# Schichtplaner

Android-App, die einer Filialleitung im Einzelhandel den Wochen-Schichtplan abnimmt.

- Mitarbeiter einmal anlegen (Vorname, Monatsstunden, welche Schichten möglich sind, Tage an denen jemand nie kann)
- Urlaub und Frei-Wünsche im Kalender antippen
- Per Knopf einen fairen Plan erstellen lassen, von Hand nachbessern, als PDF exportieren

Alles bleibt lokal auf dem Handy: keine Cloud, kein Konto, kein Server. Geplant wird mit einem Constraint-Solver, nicht mit einer KI.

Status: Planung. Die Regeln stehen in [docs/regeln.md](docs/regeln.md).
